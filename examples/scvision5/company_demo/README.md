# 公司原始 inferCNV 示例

来源为用户提供的 `6.inferCNV分析.zip`。原文件来自公司的结果解读资料包；此处完整保留 ZIP 内的 24 个文件，不推定未提供的计算环境、参数或参考细胞设置。

- [report.html](report.html)：原始报告，下载后可离线查看。
- [CNV/](CNV/)：11 对 PNG/PDF 与逐细胞 `metadata.csv`。
- 49,058 个细胞；表格列为 `cell_type, cnv_leiden, cnv_score_cell, cnv_score_cluster, cnv_status`，首列为细胞 ID。

没有重算、重绘或改写公司示例的报告、图和注释。此示例与 GSE160269 为两个独立结果。
